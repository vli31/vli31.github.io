Background, for a reader new to the paper

  • The task. Models read a string of brackets like (()()) and say whether it is well formed. Two rules fit the training data: the counting rule (same number of ( and )) and the nesting rule (every ) closes an earlier (). Only the nesting rule is right on strings such as )(.
  • ID and OOD. ID (in-distribution) test strings look like the training data; both rules give the same answer on them. OOD (out-of-distribution) test strings were chosen so the two rules disagree. A model's OOD accuracy is how often it gives the nesting-rule answer on those strings.
  • Hierarchical model: OOD accuracy ≥ 0.5, meaning it mostly follows the nesting rule. The paper trained 270 small Transformers; all reach near-perfect ID accuracy but differ in OOD accuracy.
  • Attention head: a part of a Transformer that decides which earlier positions in the string to read from. The paper's hierarchical-head score is how often, on ID strings, a head's attention separates the positions where nesting is violated from those where it is not.
  • Paper's rule: call a model hierarchical if any of its heads has a hierarchical-head score ≥ 0.8. Paper's head scores → classifier: a standard classifier (logistic regression or random forest) fit on the paper's per-layer head scores instead of using the fixed 0.8 rule.
  • Generic attention statistics: statistics of ID attention that do not use depth or nesting violations: how spread out attention is (entropy), how much goes to the start, the current token, the first or last token, and where along the string it falls. "Per layer" keeps them separate for each layer. "No bracket-type info" also drops how much attention lands on ( vs ); it gives the same results.
  • Representation geometry (Fig. B1 below): for each of 400 ID strings, take the model's internal vector at the last position after its final layer, the same vector its answer is read from. Compute how dissimilar every pair of strings is inside the model (1 − correlation of the two vectors). That 400×400 table is the model's "shape": which strings it treats as alike. Two models are compared by how well their tables agree. Used either through a classifier or by letting a new model's 5 most similar models vote on whether it is hierarchical.
  • ID answers: the model's own outputs on the 1000 ID test strings (all of them, or 5 summary numbers such as average confidence). A baseline that uses behaviour, not internals.
  • Training settings: number of layers (depth), number of attention heads, weight decay (a regularisation strength). Varied across the 270 models. A baseline that uses no measurement of the model at all.
  • Held-out prediction: fit a predictor on some models, then test it on other models it never saw. AUROC measures how well the predictor ranks hierarchical models above the others: 1.0 = perfect, 0.5 = chance.
  • t-SNE and PCA: two ways to draw high-dimensional data in 2D. PCA is a linear projection that keeps overall distances. t-SNE keeps only which points are near each other and can make a continuum look like separate clusters.
  • Cluster statistics. Silhouette: how separated clusters are (1 = clearly separated, 0 = no structure). ARI: agreement between two groupings (1 = identical, 0 = chance). Dip test: a test of whether a distribution has more than one peak.
  • Question formation (QF): the paper's second task. Models turn a statement into a yes/no question by moving an auxiliary verb ("does", "doesn't"). Two rules fit the training data: move the first auxiliary, or move the main-clause auxiliary. OOD sentences are those where the two rules disagree. The paper's feature there is a head that attends to the main-clause auxiliary. 79 models.

"t-SNE is designed to preserve local neighborhoods while distorting global geometry, so apparent clusters can arise from the visualization procedure and its hyperparameters rather than from genuinely discrete structure in the models' OOD behavior, I guess it would be good to add analysis to quantify clustering directly in the original OOD-output space and test whether models genuinely form distinct behavioral modes rather than a continuous distribution that t-SNE makes look categorical." Computed cluster statistics directly on each model's 1000 OOD answers, with no t-SNE (Fig. E2a, E2b). There is real cluster structure: silhouette 0.57, vs at most 0.39 for data with the same spread but no clusters; clusters are stable under resampling (ARI 0.98); OOD accuracy has more than one peak (dip test p<0.001). The other 162 models spread continuously from 0.2 to 1.0 OOD accuracy; 57% of all models are between 0.1 and 0.9. The main axis of variation (72% of variance) is OOD accuracy itself. The paper currently says models fall into discrete clusters. Change to: "two tight clusters (counting rule, first-bracket rule) and a continuum of partly hierarchical models (Appendix X)". Main-text paragraph (113 words; the main body still ends on page 9 and the reference list does not spill):

Held-out prediction. The association above is measured on the models used to identify hierarchical heads, so we also fit the predictor on 150 Dyck models and evaluate it on the remaining 120 (50 random splits). The rule "any ID hierarchical head" identifies held-out models that follow NESTED (OOD accuracy ≥ 0.5) with AUROC 0.88 (chance 0.50). Hyperparameters alone (depth, width, weight decay) also reach 0.88; holding out every model that shares a (depth, weight decay) setting drops hyperparameters to chance (0.49) while the ID head rule retains 0.74 (Appendix I.1). Attention statistics that never reference Equation 2 predict comparably (0.88 and 0.73): the hierarchical head is one readable instance of a broader ID signal.

Appendix Y (about half a page with Fig. P1):

Held-out prediction of OOD behaviour. Predictors use ID data only. (i) The fixed rule: any head in any layer with ID hierarchical-head score ≥ 0.8. (ii) Nesting-agnostic attention statistics: for each head, 24 statistics of its attention on the 1000 ID strings that do not reference nesting or depth (normalised entropy; attention to the start, the current, the first and the last token; centre of mass; largest weight; a 10-bin positional profile; the variability of entropy across strings; and entropy, self-, previous-token and start attention averaged over all positions), pooled as max/mean/min over all heads and over the final layer's heads, fed to a random forest. (iii) Baseline: logistic regression on training configuration (depth, heads, weight decay). Evaluation: 50 random 150/120 splits, and holding out each (depth, weight decay) setting in turn; six of the nine settings contain both classes and can be scored. In those six the ID head rule beats configuration every time (mean difference +0.26, Wilcoxon p = 0.03). The same two predictors were run in the question-formation setting (79 models; one shared configuration, so only random 5-fold splits apply): Main Auxiliary-Detecting head 0.75, nesting-agnostic statistics 0.84.

Fig. P1 (for the appendix), six bars. What is predicted: whether a held-out model follows the nesting rule on OOD strings (OOD accuracy ≥ 0.5); the predictor never sees the model's OOD behaviour. What is used to predict, all from ID strings only: the paper's rule (any attention head with ID hierarchical-head score ≥ 0.8); attention statistics that never reference nesting (entropy, attention to start/self/first/last token, positional profile, pooled over all heads, random forest); and, as a baseline, the training configuration alone (depth, heads, weight decay), with no measurement of the trained model. Blue: fit on 150 random models, tested on the other 120 (50 splits). Orange: all models sharing one (depth, weight decay) setting held out, six evaluable settings. Whiskers: ±1 SD across splits. The head rule beats configuration in all six held-out settings (Wilcoxon p = 0.03).
