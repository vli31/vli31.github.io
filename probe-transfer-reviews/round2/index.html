Fighting the Drift: probe reuse and orthogonal correction

Terms used on this page
Old probe, new probe:
the old probe was trained on an earlier checkpoint of the model (here Base); the new probe is fitted on labelled prompt groups of the later checkpoint (its fitting groups). Their outputs on a prompt are the old score and the new score. The request calls them the prior and the target.
TPR at 1% FPR:
share of positive test rows scored above the threshold that 1% of negative test rows exceed; the page's measure of detection. Differences are in percentage points.
Prompt group:
prompts that share their first eight normalised words; groups, not prompts, are assigned to fitting, estimation or test.
Estimation set:
labelled prompt groups of the later checkpoint that are set aside to estimate the overlap and to tune weights; they are never test rows.
Seed:
one of 8 random draws; each has its own old probe and its own labelled prompt groups. What else a seed fixes is said in the definitions of each experiment.
The two intervals:
"over seeds" is a 95% t interval of the 8 seed values or seed differences, with the test rows fixed; "test sampling" is a 95% interval from resampling whole test prompt groups, with the probes fixed. A third, "combined", adds both and is approximate.
Resolved:
all three intervals exclude 0 on the same side. "Unadjusted" means that no correction for the number of comparisons was applied.
Diagnostic:
an experiment or a comparison that is reported with all its intervals and is not the basis of a significance claim; its comparisons are not adjusted for their number.
Descriptive:
a comparison that was not among those fixed before the run; it is shown for context.
Setting, run, case:
in F3 a setting is one transfer at one fitting size and one weight (12 in all, 6 per transfer); a run is one transfer at one fitting size and one seed (32); a case is one seed at one setting.
Cell, prompt format:
in F2 a cell is one checkpoint (its weights) run on one prompt format; a prompt format is the text around the prompt and the token that the probe reads (the request calls it a rendering). A native cell is a checkpoint on its own format, a crossed cell a checkpoint on the other one.
Labels fixed:
in F2 every cell is scored against the same refusal labels, taken from one checkpoint's own responses; no response is generated for a crossed cell.
Native-format change, match effect:
in F2 the native-format change is D − A: weights and prompt format both change, as in Figure 2 of the paper, but under common labels. The match effect is (D − B) − (C − A): how much more the two native cells detect than the two crossed cells.
Stored activations, new extraction:
in F2 the stored activations are those behind Figure 2 of the paper; the new extraction is the set of activations extracted for this experiment, with another inference engine.
F1 to F4:
this page's names for the request's experiments 1 to 4, in the request's order.

In progress

Question. With only 100 or 500 labelled prompt groups in total, does reusing the old probe detect more than a new probe trained on all of those labels, and does the paper's orthogonal correction detect more than a direct blend of the two probes' scores tuned on the same data?

In progress: the runs or their independent verification are not complete, so this section shows no number yet.

What it will show, each as a chart with a table view:

  • Detection against the number of labelled prompt groups, for every method, on the two refusal transfers of this experiment (Base to Instruct-SFT, Think-SFT to Think-DPO), with the frozen probe at zero labels.
  • Reuse against refit: the correction, cross-fitted, minus a new probe refitted on all labels, cross-validated, with every seed, the mean and both intervals; beside it, how much the old probe gives when it is used unchanged.

Shared low-budget runs

Checkpoint pairs and budgets: OLMo-3 7B refusal, Base → Instruct-SFT and Think-SFT → Think-DPO. Use 100 and 500 total labelled groups, seeds 0–7.

What the result tells us: Compare correction with a refit for Reviewer 1 and with a signed direct blend for Reviewer 2. Reuse the same fitted probes and folds.

Why these runs are still needed

The earlier equal-budget refit started at 2,000 total groups on two refusal transfers. At 4,500 it fitted on all 4,500. Correction fitted on 3,500 and reserved 1,000 for estimation. The refit led by 0.036 AUROC percentage points on Base → Think-SFT and 0.037 on Think-SFT → Instruct-SFT. On Base → DPO harm, correction led by 0.503 points. Keep these results in the rebuttal.

Figure 19 showed a low-fitting-budget advantage on the two refusal pairs in experiment 1. Its x-axis counts fitting groups m. Its m = 100 and 500 points used 4,100 and 4,500 labelled groups including estimation. The new 100- and 500-total-group runs directly test the cheaper operating regime.

Scope of a claim across checkpoints

Both primary pairs were chosen after seeing Figure 19. Run both budgets and all eight seeds regardless of early results. Next add Instruct-SFT → Instruct-DPO and Think-DPO → Think-RLVR. For a claim across all six panels, also run Base → Think-SFT and Think-SFT → Instruct-SFT at the same budgets. Add 250 or 1,000 groups only if a finer cost curve is needed.

Comparing methods at equal label cost

Count B as the number of distinct target-labelled prompt groups accessed for fitting or tuning. Use the paper’s grouping by the first eight normalised words. For each primary transfer and seed, draw 500 eligible groups independently of their labels and use the first 100 for the smaller budget. Fix a disjoint test set before sampling B and share it across methods, budgets and seeds.

Run these methods on the same draw

Frozen source probe

Role in the comparison: Score the original source probe at zero new labels. Also score correction’s starting probe alone if target standardisation changes it. Record its activation access.

Cross-validated refit

Role in the comparison: Select regularisation inside B and fit one target direction on all B groups. Its score alone is the primary Reviewer 1 baseline.

Cross-fitted correction and cross-fitted direct blend

Role in the comparison: Give each procedure the same frozen prior, target direction and out-of-fold scores. Their held-out difference answers Reviewer 2. Fit the final target direction once and share it with the refit.

Published split correction and matched split refit

Role in the comparison: At B = 100 use 50 fitting + 50 estimation groups. At B = 500 use 250 + 250. Preassign one grouped split per seed. Follow the published tuning rules for each method. Include unstable fits.

The matched split tests the published procedure under a small total budget. The all-label runs test what is achievable when both methods can train on every group. Attribute gains to the variant actually run. Keep preprocessing, activation access, layer, class weights and selection data fixed across the relevant arms. Exclude external target-labelled tuning data from B = 100 and 500.

How to cross-fit the shared target probe

The paper used a separate estimation set E so the examples choosing the blend had scores from a probe that had not trained on them. Cross-fitting supplies a held-out score for every labelled example and leaves all B groups available for the final target probe. Treat cross-fitted correction as a new variant of Equation 5.

Fix the folds. Within each B, form five grouped folds, stratified as far as group integrity allows. At B = 100, each group is scored by a probe trained on roughly 80 groups. Keep every related prompt and response in the same fold.

Save the shared out-of-fold scores. Inside each outer training fold, tune logistic regularisation C with three-fold grouped CV on AUROC. Fit preprocessing separately inside each inner training split. Refit preprocessing and the target probe on the outer training groups. Score the outer held-out rows with the prior and the target probe. Save one score pair (u, v) per row and the fold’s directions p and g. Use Equation 5’s sign, normalisation and intercept conventions throughout.

Estimate the orthogonal correction. Pool the out-of-fold score pairs. Estimate β as the slope of v on u after subtracting each score’s class means. On held-out rows of fold k, evaluate each blend weight α using u + α(v − βu) / ‖gₖ − βpₖ‖, where pₖ is the unit prior. Use the uncentred scores for prediction. Select α on pooled out-of-fold AUROC using the paper’s bounded search on [0, 100].

Fit the final target probe once. Use grouped CV on the full B to choose C with the same rule and fit the final target direction. The refit scores that direction alone. Correction uses the saved β and α with the final prior and target directions, recomputing the residual norm. The direct blend uses its saved score coefficients with those same final directions. Apply each rule to the untouched test set.

Checks before scoring

Use the rebuttal refit’s logistic grid, solver, weighting and deterministic tie rule. If a split lacks class support, reduce the fold count to the largest feasible count of at least two. Record cells that remain unevaluable. If the correction slope or residual norm is undefined, score the prior alone and flag the fallback. Retain the original seed.

Verify that every outer held-out group was excluded from both target fitting and selection of C for its prediction. Check exactly B unique labelled groups, no train/test group or canonical-prompt overlap, and identical final target scores before combining with the prior. First reproduce a saved R1-E1 cell under its original settings.

A direct blend at 100 and 500 total labels

The reviewer’s proposed alternative tunes the two probe scores directly. With 4,000 estimation groups, the largest mean TPR difference between the paper’s rule and five alternative searches was 0.06 percentage points across the tested budgets on Base → Think-SFT refusal and Base → DPO harm. The 176/176 direction match came from giving two implementations identical candidates. It verifies the algebra. Neither result settles which rule chooses a better blend with only 100 or 500 labels in total.

Add one baseline to the shared low-budget runs

Use Base → Instruct-SFT and Think-SFT → Think-DPO refusal at layer 16, B = 100 and 500, eight paired seeds. Reuse the exact (u, v) score pairs, test prompts, CV folds, target fit and score conventions from the shared cross-fitting procedure. No extra estimation set or target model pass is needed for the direct blend.

Implement the wide signed-angle search from R2-E2. Score candidates as a weighted sum of the prior score u and target score v using its existing scale convention. Include the prior-only and target-only candidates and allow the prior coefficient to go negative. Use the standalone search range from 0° to 180°, its prespecified grid and its smallest-angle tie rule. Select on the same pooled out-of-fold AUROC as correction. Freeze the weights before applying them to the shared final scores.

Why allow negative weights? With overlapping scores, subtracting part of the prior can recover a useful target signal. In the previous refusal runs the paper’s search selected a negative prior coefficient in 27 of 88 runs. A positive-only blend would exclude those solutions. Giving the direct blend its own signed range lets it compensate for overlap independently.

Distinguish the search rule from the centring rule

The earlier small-estimation-set runs found that the bounded optimiser sometimes missed a better candidate on its own AUROC criterion. Preserve the bounded result. Also rerun split and cross-fitted correction on a prespecified dense grid of 0 plus 201 log-spaced α values from 0.0001 to 100. Break grid ties towards smaller α. Report the bounded and dense results alongside the direct search. Log coefficient ranges, resolution, tie rules and selection AUROC.

To attribute a low-budget gain specifically to within-class centring, repeat the dense correction with global centring. Change only the way β is estimated. Use the same prompts, folds, grid, norm convention and tie rule. This comparison is needed only for that stronger attribution.

Interpret the paired results

Report correction minus signed direct blend and correction minus refit for each pair and budget. If both blends beat refitting and perform similarly to each other, the results support probe reuse. A reproducible gain over the signed blend supports the correction procedure in the measured setting. If only a fixed positive blend loses, restrict the claim to that update rule. Report a direct-blend or refit win on the same terms.

Definitions and method
  • Data. OLMo-3 7B, layer 16, the activation at the last token of the prompt; no response is generated. Transfer: Base to Think-SFT, refusal. Test prompts: each seed's test set of Figure 2 of the paper, 27,759 to 27,804 prompts in 25,271 prompt groups (28,649 distinct prompts over the 8 seeds). A seed fixes the frozen probe and the test set.
  • Probe. For each seed the paper's linear refusal probe fitted on Base activations, applied unchanged with its original standardisation in all four cells. Nothing was fitted in this experiment.
  • Cells. Two checkpoints (Base, Think-SFT) crossed with two prompt formats. Base format: “User:”, the prompt, a line break and “Assistant:”; the probe reads the colon. Think-SFT format: the Think-SFT chat template with its default system message, ending in “<think>”; the probe reads the closing “>”. Within a prompt format both checkpoints receive identical token ids, positions and read position.
  • Labels, fixed in all four cells. Think-SFT labels (primary): a prompt is positive when most of Think-SFT's sampled responses to it were judged refusals (8,114 to 8,173 positives per seed). Base labels (sensitivity): the same rule on Base's responses (4,644 to 4,680 positives). These are the paper's existing labels: no response was generated and none was judged here.
  • Detection. TPR at 1% FPR: the threshold is the 99th percentile of the scores of the negative test prompts, and TPR is the share of positive test prompts strictly above it. Realised FPR 0.995% to 1.000% (195 to 231 false positives) in every cell, seed and label set. It is a point of the test ROC curve, not a deployed threshold. AUROC is the secondary measure.
  • Intervals. Over seeds: paired t interval of the 8 seed differences (for a level, t interval of the 8 seed values). Test sampling: 2,000 bootstrap draws of whole prompt groups from the 26,071 test groups, one draw shared by all cells, label sets and seeds, with the probes fixed and the threshold recomputed in each draw. Combined: both standard errors added in quadrature, with the t quantile of the seeds (approximate). Resolved (unadjusted): all three 95% intervals exclude 0 on the same side.
  • Fixed before the run: the cells, the prompt formats, the primary and the sensitivity label set, the six differences, the intervals, the rule for “resolved”, the wording of each outcome and the limits of the check of the extraction. The six differences are outside the family of comparisons that the request asks to adjust (those of F1), so they are unadjusted.
  • New extraction. All four cells were extracted in one run, with one inference engine. Cells A and D were compared with the stored activations behind Figure 2, which were made with another inference engine, before a crossed cell was scored. A difference smaller than the largest gap of an 8-seed mean TPR in that check (0.13 points) would not be interpreted; none is.
  • Extensions. The second transfer and the series along training were run after the primary analysis had been verified. They are diagnostic: reported with all intervals and not the basis of a significance claim.

What this experiment cannot show (fixed labels; format and token read change together; cell B; no adjustment for the number of comparisons)
  • One model family (OLMo-3 7B), one layer, the last token of the prompt, linear probes, one frozen probe per transfer.
  • The labels are fixed labels from native responses. The cells show how each representation ranks the same labelled prompts, not how a checkpoint behaves under a swapped prompt format; that would need new responses and new judgements of them.
  • System message, chat tokens and the token that the probe reads change together between the two prompt formats; their separate contributions are not identified. Cell B gives Base five chat tokens that Base was probably not trained on (an inference, not a documented fact).

  • A fixed-weight comparison holds the weight of the new score fixed. It cannot show an advantage over a direct blend with tuned weights, and it is not the paper's correction, which normalises what is left after the subtraction and tunes its weight. The refusal result is therefore a statement about raw addition at a fixed positive weight only.

  • The weight c acts on scores scaled to SD 1 on the estimation set; another scale would give other positions for the same c. Three values of c were tested; nothing is shown for other values.

What the result tells us: Tests whether adding the shared score component hurts detection at a fixed update size. Use saved scores where available.

Testing whether the raw update overweights the prior

Suppose the target score v contains both a copy of the prior score u and a useful residual r, with v = βu + r. At a fixed positive update size c, raw addition gives (1 + cβ)u + cr. Subtracting the estimated overlap first gives u + cr. Both updates add the same residual. Comparing them tests whether changing the coefficient on the prior improves detection.

Use the saved scores from Reviewer 2

Use Base → Think-SFT refusal and Base → DPO harm, layer 16. Run m = 100 and 500 fitting groups, |E| = 4,000 estimation groups, seeds 0–7. These runs cover both concepts and the published low-m regime. Reuse stored per-example scores if their IDs and fitted probes match. If necessary, regenerate scores for those saved probes and splits. No new labels are required.

Hold the update size fixed

Estimate the overlap. For each seed and budget, put u and v on comparable scales using means and standard deviations from E only. Apply the same transforms to test scores. On E, subtract each class mean from each standardised score. Estimate β as the sum of the cross-products of these centred scores divided by the sum of squared centred prior scores. Freeze β and the scale factors.

Score both fixed updates. Prespecify c = 0.25, 0.5 and 1. At every c score u + cv and u + c(v − βu). Keep u, v, the fitted probes and c identical across the two updates. Use the same update scale throughout, without renormalising the residual separately. This diagnostic holds the residual contribution fixed. Use the published normalisation for the actual correction benchmarks.

Check overlap and detection separately. Measure the pooled within-class correlation of u with v, then of u with v − βu, on the held-out data. Centre by test class only for this descriptive statistic. Score predictions with the frozen transforms and β. Report signed correlations, their magnitudes and β. Flag zero variances. Compute paired TPR at 1% FPR and AUROC for each c, alongside the published correction and the independently tuned signed direct blend from the same run.

What would support the explanation

The residual’s pooled within-class covariance with the prior is zero on E by construction. Reduced overlap on test asks whether that estimate generalises. If β is positive, overlap falls and the residual update improves held-out detection, raw addition overweighted the prior at that c. If overlap falls and detection barely moves, the mechanism is visible but its practical benefit is unresolved. Report every c and both transfers. A fixed-weight gain alone cannot establish an advantage over the tuned direct blend.
